# Treinamento Ao Vivo - Landing Page com Efeito Matrix

Landing page profissional para treinamento de criação de sites e apps com IA.

## ✨ Recursos

- **Efeito Matrix** de fundo animado (chuva de código verde)
- Design moderno e responsivo
- Otimizado para conversão
- Cores e estilos futuristas

## 📸 Imagens Necessárias

Adicione as seguintes imagens na raiz do projeto:

- `hero-suafoto.png` - Imagem do ambiente de treinamento
- `sites-suafoto.png` - Exemplos de sites
- `instrutora-suafoto.png` - Foto da instrutora
- `mockup-suafoto.png` - Mockup do treinamento

## 🚀 Como Usar

1. Adicione suas imagens no diretório raiz
2. Abra o arquivo `index.html` no navegador
3. Personalize conforme necessário

## 🎨 Efeito Matrix

O efeito Matrix foi implementado usando canvas e JavaScript puro, criando uma animação de fundo sutil que não interfere na leitura do conteúdo.
